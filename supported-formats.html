Supported file formats.

A complete reference for code, data, documents and subtitles. Find your file extension, see what the format contains, and choose the product that supports it.

Formats with a dedicated viewer

Both products means the Chrome / Edge browser extension and the Windows app. CSV, HTML, WebVTT and unified patches have dedicated viewers in the Windows app.

Other text files

Files such as .txt, .log, .ini and .cfg, other text-based source files, and files without an extension can be opened manually as read-only plain text. Use the extension’s file picker or drag-and-drop area, or open them in the Windows app. This text view preserves the source without language-specific formatting or validation.

In the browser, a supported HTTP content type can also identify a resource without a matching file extension. Ordinary web pages are left alone; the HTML source viewer is a Windows app feature.

See the manual’s compatibility table for default views and the getting-started instructions for opening files.
